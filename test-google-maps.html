🗺️ Prueba de Google Maps API - Rodavia

⏳ Cargando Google Maps API...

📋 Instrucciones:

  1. Abre las Herramientas de Desarrollo (F12)
  2. Ve a la pestaña "Console"
  3. Busca mensajes de error relacionados con Google Maps
  4. Si ves un mapa de Santiago con 2 marcadores, ¡funciona! ✅

❌ Errores Comunes:

  • RefererNotAllowedMapError: La URL no está autorizada en Google Cloud Console
  • ApiNotActivatedMapError: Maps JavaScript API no está habilitada
  • InvalidKeyMapError: La clave API es inválida
  • Mapa gris/vacío: Problema de facturación en Google Cloud
